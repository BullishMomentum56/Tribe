❓ TROUBLESHOOTING:

Q: Build fails locally?
A: Run: npm install --legacy-peer-deps

Q: Port 3000 in use?
A: Run: lsof -i :3000 && kill -9 <PID>

Q: Can't access from browser?
A: Check firewall: sudo ufw allow 3000

Q: Server shows error?
A: Run: pm2 logs tribe
